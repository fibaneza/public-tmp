Runnable Python companions to the documents in xref:../README.adoc[AI/rag].
Every file is self-contained, heavily commented, and executable on its own.

== Setup

[source,bash]
----
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Only the generation / judging examples need a key:
export ANTHROPIC_API_KEY=sk-ant-...
----

The first run downloads embedding and reranker weights (~500 MB for the
defaults). Examples that only do retrieval work offline once the weights are
cached; examples that call an LLM are marked below.

== Suggested reading order

[source,text]
----
naive_rag.py                  # the baseline everything is measured against
  └─ chunking_strategies.py   # the decision that constrains all the others
     └─ embeddings_lab.py     # what the vectors actually encode
        └─ hybrid_search.py   # first real accuracy jump
           └─ cross_encoder_rerank.py   # second, larger jump
              └─ contextual_compression.py
                 └─ citations.py + conversational_memory.py
                    └─ ragas_eval.py    # now you can measure the above
                       └─ production_rag_pipeline.py
----

Query-transformation files (`hyde.py`, `rag_fusion.py`, `rewrite_retrieve_read.py`)
and structural ones (`parent_child_retriever.py`, `hierarchical_rag.py`,
`agentic_rag.py`) can be read in any order once hybrid search makes sense.

== A note on the corpus

`_common.py` defines six chunks chosen to be adversarial on purpose:

* an acronym that appears exactly once (`PIT`) — dense search misses it, BM25 nails it
* a numeric fact (`14 days`) — the classic lexical-match case
* two near-duplicate architecture chunks — where reranking earns its latency
* a paraphrase gap ("roll back" vs "undo a release") — where BM25 fails and dense wins

That is enough to make every technique's win or loss visible in one terminal
screen. Swap `CORPUS` for your own documents to see whether the same ordering
holds — it usually does not, which is the whole argument for `ragas_eval.py`.
